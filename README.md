## 01 · Selected Work

### geo-areas-php · Interactive area map

Draw polygons on a Leaflet map, save them to PostgreSQL with PostGIS, and view them again. Area (km²) and perimeter (km) are calculated with PostGIS geography functions.

`PHP` · `PostgreSQL` · `PostGIS` · `Leaflet` · `Docker Compose`

[Repository](https://github.com/decoarc/geo-areas-php)

### LEC · Local Email Client

A Windows desktop app that opens Outlook Express profiles (`.dbx` files) to read, search, and reorganize messages and folders. A backup is saved before any `.dbx` file is rewritten.

`C#` · `.NET 9` · `WPF` · `WebView2` · `MimeKit`

[Repository](https://github.com/decoarc/Local_Email_Client-LEC)
